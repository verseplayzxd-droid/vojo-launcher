## What changed

- System-browser Microsoft code grant with random state, S256 PKCE, registered debug/release native redirects, ten-minute expiry and one-time callback consumption. Browser callbacks wait for encrypted-vault initialization after process recreation.
- Microsoft → Xbox Live → XSTS → Minecraft Services authentication, Java entitlement and profile verification, token refresh/rotation, saved account selection/removal and an explicit online launch-session boundary for M5.
- A Keystore-backed AES/GCM vault in app-private no-backup storage; API 21/22 use an RSA-wrapped AES key, API 23+ use a Keystore AES key. No new production dependency.
- A Compose Accounts screen from Home/Settings with dark/light previews, loading/empty/offline/error presentations, cancellation, reset/removal confirmations and clear child/Xbox/profile/ownership errors. `Invalid app registration` explicitly says Vojo is waiting for Mojang approval.
- Disabled inherited borrowed-ID, WebView password, token-logging, plaintext-save/import and offline/demo paths. Internal package/class names and JNI interfaces remain intact. Historical account files are not imported or silently erased; see [security limits](../auth/SECURITY.md).
- Approved **JUnit 4.13.2 only as testImplementation**. Its normal Hamcrest Core 1.3 transitive dependency is also test-only. CI runs auth tests before assembly; APK verification rejects JUnit/Hamcrest in packaged DEX.
